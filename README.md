# Trading Platform
A full-stack trading platform built with the MERN stack that simulates the core functionalities of a stock trading application.
Users can create an account, securely log in, manage their portfolio, place buy/sell orders, and view their transaction history through a clean and responsive interface.

Created this project only for learning perpose code is here with many bugs and wanting to make it good.

## Feature
- Introduction Page
- Dashboard
- JWT Authentication
- User Registration & Login
- Buy & Sell Orders
- Portfolio Management
- Order History
- Adding fund
- REST API
- Responsive UI

## Tech Stack
### Frontend
- React.js
- React Router
- Axios
- CSS
- chart.js
- react-toastify


### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt
- cors
- jsonwebtoken
- cookie-parser
- body-parser

### Database

- Mongoose
